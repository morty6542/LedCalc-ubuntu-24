Запуск на Ubuntu 24.04

Положи run.sh рядом с index.html и выполни:

bash
chmod +x run.sh
./run.sh          # или ./run.sh 8081, если порт 8080 занят

Скрипт поднимет локальный сервер на встроенном python3 (в 24.04 он есть из коробки) и откроет браузер. Сервер раздаёт родительскую папку, поэтому ссылки ../index.html и ../favicon.svg работают.
